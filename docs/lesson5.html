Lesson 5: Regression, Linearity & Dose-Response

EOH 635 — Environmental Epidemiology Methods

Author

Leah Schinasi

Published

In Lesson 4 you decided how to code your exposure. This lesson puts that exposure into a regression model: choosing a model based on your outcome, interpreting the estimate it produces, and checking whether the assumption that the exposure is related to the outcome “in a straight line” actually holds. It has two parts:

  1. Choosing, fitting, and interpreting a crude model — starting from a two-by-two table you can calculate by hand, then making the same comparison with a logistic and a log-binomial regression model, then entering the exposure as a continuous term. Worked example: tree canopy cover and high blood pressure, the course’s primary exposure–outcome relationship.
  2. Checking the linearity assumption — categorizing the exposure, fitting a model with one indicator term per category, and plotting the estimates to see whether the relationship really is a straight line.

Both parts end with a 🧠 Your Turn for the exposure and outcome in your own project. Together they produce the crude model and the evaluation of functional form that Milestone 2 asks for.

A reminder: how is tree canopy coded?

Before modeling an exposure, remind yourself what its values mean and what its distribution looks like — you characterized this in Lesson 3, and it matters again here.

A few things to keep in mind about hrlctree:

  • It is a proportion, from 0 to 1: a value of 0.12 means 12% of the participant’s census tract is covered by tree canopy. In our data it ranges from about 0.02 (2%) to 0.63 (63%), with a median of about 0.12 (12%).
  • It is measured at the census-tract level, not for each person: every participant who lives in the same tract has the same value. The 2,000 participants live in 363 tracts.
  • It is right-skewed: most participants live in tracts with 5–20% canopy, and a small number live in much greener tracts. Keep this in mind in Part 2 — it affects how wide each quartile is.

Step 1: What kind of outcome do you have — and is it rare or common?

The type of outcome determines the model. high_blood_pressure is binary (1 = diagnosed, 0 = not), so a linear regression model is not appropriate — we need logistic or log-binomial regression. Which of those two to prefer depends on whether the outcome is rare or common.

Questions to consider:

  • What proportion of participants have high blood pressure? Would you call that rare or common?
  • How many participants are missing this outcome?
Note💡 Answers — click to reveal after you’ve thought about it
  • About 30% of participants with data (606 of 1,988) have high blood pressure. That is a common outcome — a rough rule of thumb is that an outcome is “rare” if it affects fewer than about 10% of people.
  • 12 participants are missing high_blood_pressure. R will drop them automatically from every model below, so all models are fit on the 1,988 participants with data.

Step 2: A two-by-two table you can calculate by hand

Before fitting any model, let’s calculate the association the old-fashioned way, so you can see exactly what the regression model will reproduce. We’ll use tree canopy dichotomized at the median — the same kind of binary exposure you created in Lesson 4.

What each step of the code does:

  1. Create a binary exposure. median(hrlctree, na.rm = TRUE) finds the median tree canopy value (about 0.12, or 12%); na.rm = TRUE tells R to ignore any missing values when doing so. ifelse() then checks each participant: if their tract’s canopy is above the median, the new variable tree_high is set to 1 (“high canopy”); otherwise it is set to 0 (“low canopy”). mutate() adds tree_high to the data as a new column, leaving hrlctree unchanged.
  2. Build the two-by-two table. table() counts how many participants fall into each combination of tree_high (the rows) and high_blood_pressure (the columns). The names before the = signs (Tree_high, HBP) are just labels for the printed table. Typing two_by_two on its own line prints it. Participants missing high_blood_pressure are left out of the table.
  3. Save the four counts. Each line stores one cell of the table under a letter — A, B, C, or D — so that we can use it in the formulas that follow. The numbers in square brackets tell R which cell to take: the first is the row and the second is the column. The table below the code shows which group of people each letter represents.
  4. Calculate the prevalence in each group. Prevalence is the number of people with the outcome divided by everyone in that group. Among high-canopy participants that is A / (A + B); among low-canopy participants it is C / (C + D).
  5. Calculate the measures of association. The prevalence ratio divides the prevalence in the high-canopy group by the prevalence in the low-canopy group. The odds ratio is the cross-product (A × D) / (B × C). c() combines the four results into one labeled list, so they print together.

Each of the four cells in the table counts a different group of people:

High blood pressure (HBP = 1) No high blood pressure (HBP = 0)
High canopy (tree_high = 1) A = people in high-canopy tracts with high blood pressure B = people in high-canopy tracts without high blood pressure
Low canopy (tree_high = 0) C = people in low-canopy tracts with high blood pressure D = people in low-canopy tracts without high blood pressure

Note that R prints the table with the 0 (low canopy, no high blood pressure) row and column first, so the printed table is arranged D, C / B, A — which is why the code picks each count out by position.

NotePrevalence, not risk

Because the class dataset is a cross-sectional survey — everyone was surveyed at one point in time — we are comparing the prevalence of high blood pressure (who has it now), not the risk of developing it over follow-up. That is why we call this a prevalence ratio rather than a risk ratio.

Questions to consider:

  • What is the prevalence of high blood pressure in each canopy group?
  • Is the prevalence ratio (PR) or the odds ratio (OR) further from the null value of 1? Why does that happen with an outcome this common?
Note💡 Answers — click to reveal after you’ve thought about it
  • The prevalence is 25.5% in high-canopy tracts (252 of 987) and 35.4% in low-canopy tracts (354 of 1,001).
  • PR = 0.255 / 0.354 = 0.72; OR = 0.63. The OR is further from the null. Odds are prevalence divided by one minus prevalence, p / (1 − p). When p is small, 1 − p is close to 1, so odds and prevalence are nearly the same. When p is large (here, around 0.3), dividing by 1 − p stretches the odds away from the prevalence, and the OR ends up further from 1 than the PR. Describing the OR of 0.63 as if it were a PR would overstate how much lower high blood pressure is in greener tracts.

Step 3: The same comparison as a regression model

Now, we will make the same comparison, running both a logistic and a log-binomial regression model. We will use the results from these models to calculate the odds ratio and its 95% confidence interval (CI), and the prevalence ratio and its 95% CI.

The two models differ only in their link function — what the model treats as a straight-line function of the exposure:

  • Logistic regression, binomial(link = "logit"), models the log odds of the outcome.
  • Log-binomial regression, binomial(link = "log"), models the log prevalence.
NoteWhy do we exponentiate the coefficient and the CI?

Because both models work on the log scale, the coefficient R reports for tree_high is not a ratio — it is a difference in logs. For the log-binomial model:

  • log(prevalence in high-canopy tracts) = β₀ + β₁
  • log(prevalence in low-canopy tracts) = β₀
  • the difference, β₁, is log(prevalence high) − log(prevalence low) = log(PR)

To get back from log(PR) to the PR itself, we undo the log by exponentiating: PR = exp(β₁). (The same logic applied to log odds gives OR = exp(β₁) for the logistic model.)

The 95% CI is built on the same log scale, as β₁ ± 1.96 × SE, so we exponentiate its two endpoints the same way: exp(β₁ − 1.96 × SE) and exp(β₁ + 1.96 × SE). That is also why ratio CIs are not symmetric around the estimate — they are symmetric on the log scale, not on the ratio scale.

The extract_ratio() helper below does these steps for us: it pulls out each coefficient and its standard error, then exponentiates the coefficient and both CI endpoints. It is the same idea as the extract_or() function from Lesson 4, just renamed because it now produces prevalence ratios as well as odds ratios.

Questions to consider:

  • Compare each estimate to the one you calculated by hand in Step 2. Do they match?
  • Write a one-sentence interpretation of the PR and its 95% CI.
Note💡 Answers — click to reveal after you’ve written your own
  • Yes — the logistic model’s OR (0.63) and the log-binomial model’s PR (0.72) match the two-by-two table exactly. A crude model with a single binary exposure is doing the same calculation as the table; what the model adds is a confidence interval, and (from next week) the ability to adjust for other variables.
  • Example interpretation: The prevalence of high blood pressure among participants living in census tracts with tree canopy above the median was 0.72 times the prevalence among those living in tracts at or below the median (95% CI: 0.63, 0.83) — about 28% lower. Because the whole CI is below 1, the data are not consistent with no association (a PR of 1).

Step 4: Entering the exposure as a continuous term

Dichotomizing at the median throws away information: someone at the 51st percentile of tree canopy is treated the same as someone at the 99th. Entering hrlctree as a continuous term uses all the information available. But recall that hrlctree is a proportion (0 to 1), so a “one-unit increase” would mean going from 0% to 100% canopy — a meaningless comparison. We rescale so that one unit equals a 10-percentage-point increase in tree canopy cover (for example, from 10% to 20%).

Questions to consider:

  • Interpret the PR per 10-percentage-point increase in tree canopy.
  • This model assumes that every 10-point increase — from 5% to 15%, or from 40% to 50% — multiplies prevalence by the same amount. Is that a reasonable assumption?
Note💡 Answers — click to reveal after you’ve thought about it
  • Each 10-percentage-point increase in census-tract tree canopy cover was associated with a 24% lower prevalence of high blood pressure (PR = 0.76; 95% CI: 0.70, 0.84).
  • We can’t tell from this model — a single continuous term will return one PR no matter what the true shape of the relationship is. That is exactly what Part 2 checks.
Note💡 What if my log-binomial model won’t converge?

Log-binomial models sometimes fail with an error like “no valid set of coefficients has been found: please supply starting values”. This happens because predicted prevalences must stay below 1, which the fitting algorithm can struggle with — especially when an exposure has a few extremely high values. Two common fixes:

  1. Supply starting values. Set the intercept to the log of the overall prevalence and the other coefficients to 0, e.g. start = c(log(0.3), 0) for a model with one exposure term.
  2. Use a modified Poisson model — a Poisson model with robust (“sandwich”) standard errors, which also estimates a prevalence ratio.

Code: running a modified Poisson model (in RStudio)

# Packages for robust ("sandwich") standard errors -- install once with install.packages()
library(sandwich)
library(lmtest)

# Fit a Poisson model with a log link (same outcome and exposure as the log-binomial model)
model_pois <- glm(high_blood_pressure ~ hrlctree_10, data = data,
                  family = poisson(link = "log"))

# Replace the usual standard errors with robust ones
robust_se <- vcovHC(model_pois, type = "HC0")

coeftest(model_pois, vcov = robust_se)      # coefficients with robust SEs
exp(coef(model_pois))                       # PR point estimate
exp(coefci(model_pois, vcov = robust_se))   # PR 95% CI

Note💡 Example: traffic density (ctb1traff) and asthma — click to reveal

Interpretation: the prevalence of asthma among participants living in census tracts with traffic density above the median was 1.81 times the prevalence among those in tracts at or below the median (95% CI: 1.37, 2.38).

Asthma affects only about 10% of participants, so the OR (1.93) and PR are closer to each other here than they were for high blood pressure — the rarer the outcome, the better the OR approximates the PR.

Why dichotomize rather than enter traffic as a continuous term? Traffic density is very right-skewed — a handful of tracts have traffic many times higher than everyone else — and a log-binomial model with continuous traffic fails to converge for exactly the reason described in the “won’t converge” box above. The quartile approach in Part 2 is another way to handle it.

Part 2: Checking the Linearity Assumption

The continuous model in Step 4 produced one number to summarize the whole relationship. The check below asks whether that one number is a fair summary. The steps:

  1. Categorize the exposure into several groups (quartiles here).
  2. Fit a model with a separate indicator term for each category, compared with a reference category.
  3. Plot the estimates. If they change by roughly the same amount from one category to the next, the linearity assumption is reasonable; if they bend, level off, or jump, it isn’t.

Step 1: Categorize tree canopy into quartiles

ntile(hrlctree, 4) sorts participants from lowest to highest tree canopy and splits them into four groups of (nearly) equal size — 500 participants each:

  • Q1 — the 25% of participants living in the least green tracts (about 2% to 8% canopy)
  • Q2 — the next 25% (about 8% to 12% canopy)
  • Q3 — the next 25% (about 12% to 18% canopy)
  • Q4 — the 25% of participants living in the greenest tracts (about 18% to 63% canopy)

Notice that the quartiles have equal numbers of people, not equal ranges of canopy: because canopy is right-skewed, Q4 spans a much wider range of canopy (about 45 percentage points) than Q1–Q3 combined (about 16).

Look at the last column: prevalence of high blood pressure is about 35–36% in Q1 and Q2, 31% in Q3, and 20% in Q4.

Step 2: Fit the model with quartiles as indicator terms

Wrapping the quartile variable in factor() is what tells R to create a separate indicator term for each category. Without it, R treats 1, 2, 3, 4 as a continuous number and returns a single coefficient — which would assume linearity instead of testing it.

What “ref = Q1” means. With a categorical exposure, R needs a reference category that every other category is compared with. By default it uses the first level — here, Q1, the least green quartile. Q1 therefore does not get its own row in the output: its PR is 1 by definition. Each PR you see is the prevalence of high blood pressure in that quartile divided by the prevalence in Q1. That is why every interpretation below says “compared with participants in the lowest quartile.”

Interpreting the results:

Quartile PR (95% CI) Interpretation
Q1 (2–8% canopy) 1 (reference) The comparison group for every other row
Q2 (8–12%) 1.03 (0.87, 1.22) Prevalence essentially the same as Q1 (3% higher). The CI includes 1, so the data are consistent with no difference.
Q3 (12–18%) 0.89 (0.74, 1.06) Prevalence 11% lower than Q1, but the CI still includes 1, so this could plausibly be no difference.
Q4 (18–63%) 0.58 (0.47, 0.72) Prevalence 42% lower than Q1. The whole CI is below 1: the data are not consistent with no difference.

In words, for Q4: the prevalence of high blood pressure among participants living in the greenest quarter of tracts was 0.58 times the prevalence among those in the least green quarter (95% CI: 0.47, 0.72).

Step 3: Plot the estimates

We plot each quartile’s PR, with Q1 fixed at 1, against the quartile itself. Each quartile gets the same amount of space on the x-axis, so you can see directly how much the PR changes from one quartile to the next. The canopy range of each quartile is shown under its label.

The y-axis is on a log scale because the log-binomial model is linear on the log scale: if the linearity assumption holds, the PRs should step down (or up) by about the same amount from each quartile to the next.

Questions to consider:

  • Do Q1, Q2, and Q3 look different from each other? Where does most of the change happen?
  • Does the line fall at a steady rate across the quartiles, or does it stay flat and then drop?
  • Now look at the canopy ranges under each label. How does the width of Q4 change your reading of the “drop”?
  • Given this plot, would you keep tree canopy as a single continuous term, use the quartile categories, or collapse some categories together?
Note💡 Discussion — click to reveal after you’ve looked at the plot yourself

Q2 is essentially the same as Q1, Q3 is slightly lower, and Q4 is much lower (PR ≈ 0.58). On this plot the line is roughly flat from Q1 to Q3 and then drops sharply to Q4 — not the steady, equal-sized steps we would expect if the linearity assumption held. That is a sign the assumption may not hold.

The canopy ranges add an important caveat. The quartiles are equal-sized groups of people, not equal-width ranges of canopy: Q1–Q3 together cover only about 2% to 18% canopy, while Q4 alone covers about 18% to 63%. Part of the “sudden drop” is simply that Q4 contains a much wider — and much greener — range of tracts. Measured in canopy percentage points, the decline above roughly 10% canopy is more gradual than this plot makes it look. This is why it is always worth checking what range of the exposure each category covers before interpreting the shape.

There is no single right answer about what to do next — reasonable options include:

  • Keep the continuous term, if you judge the departure from linearity to be small. It is the most efficient and easiest to communicate (one PR per 10 percentage points).
  • Collapse categories that look alike. Here, Q1–Q3 could be combined into one reference group and compared with Q4 (the top quartile): fewer coefficients, and the estimate reflects where the change actually appears.
  • Use a flexible term such as a spline (optional section below).

Whatever you choose, justify it using the plot, your sample size in each category, and what will be most meaningful for your research question.

Collapsing categories that look alike

Question to consider: interpret this PR. How is it different from the PR for tree canopy dichotomized at the median (Part 1, Step 3), and why?

Note💡 Answer — click to reveal after you’ve thought about it

The prevalence of high blood pressure among participants in the top quartile of tree canopy was 0.60 times the prevalence among participants in the lower three quartiles combined (95% CI: 0.49, 0.72) — about 40% lower.

This is further from the null than the median-dichotomized PR (0.72) because the comparison is different. Dichotomizing at the median puts Q3 in the “high canopy” group, even though Q3’s prevalence is close to Q1 and Q2’s; that dilutes the contrast. Comparing Q4 with Q1–Q3 separates the groups where the difference actually appears.

Optional: relaxing linearity with a spline

You will not be required to use splines in this course, but they are common in environmental epidemiology (for example, temperature–mortality curves). A natural cubic spline lets the relationship bend smoothly instead of forcing a straight line. df sets how flexible the curve is.

NoteWhy doesn’t the “linear” model look like a straight line?

In the first plot, the curve labeled “Linear” bends. That’s because the log-binomial model is linear in the log of prevalence, not in prevalence itself: log(P) = β₀ + β₁ × canopy. Undoing the log gives P = exp(β₀ + β₁ × canopy), which is a curve — each additional percentage point of canopy multiplies prevalence by the same amount (the PR), rather than subtracting the same amount. In the second plot, with the y-axis on a log scale, the “Linear” model is a straight line. The linearity assumption we are checking is always about the scale the model works on — here, the log scale.

Question to consider: the spline and the linear model have almost identical AIC values. What does that suggest about how much the linearity assumption actually matters for this particular exposure and outcome?

Note💡 Answer — click to reveal after you’ve thought about it

The spline allows the curve to bend wherever the data suggest, yet it fits the data no better than a single straight line on the log scale (the AICs differ by less than 1). The two curves differ mainly at the lowest canopy values, where the spline levels off, and slightly at the highest values, where few participants live. So, for tree canopy and high blood pressure, the linearity assumption appears to be a reasonable approximation, and a continuous term per 10 percentage points is a defensible choice. The quartile plot is still valuable: it shows where along the canopy range the association is concentrated.

Quick-Start Script for Your Own Project

Tip💻 In your RStudio script 
# ---- Setup ----
library(tidyverse)

# ---- Read in your processed data ----
data <- read.csv(file.path("data_processed", "class_data_processed.csv"))

# ---- Helper: exponentiate coefficients and 95% CIs ----
extract_ratio <- function(model, label) {
  b  <- coef(model)[-1]
  se <- sqrt(diag(vcov(model)))[-1]
  data.frame(Model = label, Term = names(b), Estimate = exp(b),
             CI_Lower = exp(b - 1.96 * se), CI_Upper = exp(b + 1.96 * se),
             row.names = NULL)
}

# ============================================================
# REPLACE: swap in your own exposure and outcome variable names
# ============================================================

# ---- Outcome: binary or continuous? rare or common? ----
table(data$YOUR_OUTCOME, useNA = "ifany")
prop.table(table(data$YOUR_OUTCOME))

# ---- Look at your exposure's coding and distribution ----
summary(data$YOUR_EXPOSURE)
hist(data$YOUR_EXPOSURE)

# ---- OPTIONAL: rescale a continuous exposure ----
# Only needed if a one-unit change isn't meaningful for your exposure. For a proportion
# (0-1, like tree canopy), multiplying by 10 makes one unit = 10 percentage points.
# Choose the scaling based on your exposure's units and distribution -- or skip this step
# and use YOUR_EXPOSURE directly below.
data <- data %>% mutate(YOUR_EXPOSURE_scaled = YOUR_EXPOSURE * 10)   # adjust the scaling

# ---- Crude model, continuous exposure ----
model_cont <- glm(YOUR_OUTCOME ~ YOUR_EXPOSURE_scaled, data = data,
                  family = binomial(link = "log"))   # continuous outcome: lm(YOUR_OUTCOME ~ ...)
extract_ratio(model_cont, "Continuous")

# ---- Linearity check: quartiles as indicator terms ----
data <- data %>% mutate(YOUR_EXPOSURE_quartile = factor(ntile(YOUR_EXPOSURE, 4)))

data %>%                                   # exposure range in each quartile
  group_by(YOUR_EXPOSURE_quartile) %>%
  summarise(n = n(), min = min(YOUR_EXPOSURE, na.rm = TRUE), max = max(YOUR_EXPOSURE, na.rm = TRUE))

model_quart <- glm(YOUR_OUTCOME ~ YOUR_EXPOSURE_quartile, data = data,
                   family = binomial(link = "log"))

results <- extract_ratio(model_quart, "Quartiles") %>%
  mutate(YOUR_EXPOSURE_quartile = factor(2:4)) %>%
  bind_rows(data.frame(YOUR_EXPOSURE_quartile = factor(1), Estimate = 1,
                       CI_Lower = 1, CI_Upper = 1)) %>%
  mutate(YOUR_EXPOSURE_quartile = factor(YOUR_EXPOSURE_quartile, levels = 1:4)) %>%   # put Q1 first
  arrange(YOUR_EXPOSURE_quartile)

ggplot(results, aes(x = YOUR_EXPOSURE_quartile, y = Estimate, group = 1)) +
  geom_hline(yintercept = 1, linetype = "dashed", color = "red") +
  geom_errorbar(aes(ymin = CI_Lower, ymax = CI_Upper), width = 0.15) +
  geom_point(size = 3) +
  geom_line() +
  scale_x_discrete(labels = c("Q1", "Q2", "Q3", "Q4")) +
  scale_y_log10() +
  labs(x = "[Exposure] quartile", y = "Prevalence ratio (95% CI)",
       title = "[Outcome] by [exposure] quartile (reference = Q1)") +
  theme_minimal()

Wrap Up
